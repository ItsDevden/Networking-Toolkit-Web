## 🌐 Networking Toolkit Web

Access the Networking Toolkit directly from your browser, on desktop or mobile. No installation required.

[![Launch Web Toolkit](https://img.shields.io/badge/Launch_Web_Toolkit-238636?style=for-the-badge&logo=githubpages&logoColor=white)](https://itsdevden.github.io/Networking-Toolkit-Web/)

Just an excel sheet that got slightly out of hand.




### For the nerds

- **Frontend:** HTML5, CSS3, and vanilla JavaScript. All network calculations and UI interactions run directly in the browser.
- **Networking:** Binary operations, CIDR calculations, IPv6 prefix manipulation, and subnet allocation algorithms power the addressing tools.
- **Topology:** Interactive device placement, connections, and physical/logical layouts are stored as structured project data.
- **Storage:** Solo configurations are saved locally in the browser, while shared group configurations are stored in Supabase PostgreSQL.
- **Near Live Sync:** Clients communicate with Supabase through HTTPS, polling for changes approximately every 1.8 seconds. Revision checks help detect conflicting edits.
- **Authentication:** Group members join using generated codes without creating accounts. Admin access uses Supabase Authentication and backend authorization.
- **Hosting:** GitHub Pages serves the static website, while Supabase handles shared data and synchronization.
- **Offline Support:** Core networking tools run locally in the browser, with an optional downloadable offline version. Group collaboration requires an internet connection.
