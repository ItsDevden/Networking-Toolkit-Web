## 🌐 Networking Toolkit Web

Access the Networking Toolkit directly from your browser, on desktop or mobile. No installation required.

[![Launch Web Toolkit](https://img.shields.io/badge/Launch_Web_Toolkit-238636?style=for-the-badge&logo=githubpages&logoColor=white)](https://itsdevden.github.io/Networking-Toolkit-Web/)

What started as a simple subnet calculator turned into a full networking toolkit, courtesy of a few too many 3 AM hyperfixation sessions.

Built as a personal project while studying IT infrastructure, DevDen combines subnetting, VLSM/FLSM planning, IP management, interactive network topology design, device checklists, and a rich-text notes editor into one browser-based workspace.

Now featuring live group collaboration.

Using GitHub Pages for hosting and Supabase (PostgreSQL) as the backend, users can create private groups, join with a simple code, and work on shared network configurations without creating accounts.

Group configurations are synchronized through periodic updates and revision checks, allowing members to see changes across devices and browsers. Solo projects remain locally accessible, with the option to transfer complete configurations between Solo and Group workspaces.

The toolkit is built using HTML, CSS, and vanilla JavaScript, with browser storage for local projects and Supabase for shared group data.

No subscriptions, no mandatory accounts, and no unnecessarily complicated setup.

Just a networking toolkit that got slightly out of hand.
